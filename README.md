# 🌍 INDIA AIR QUALITY ANALYTICS 2026

##  Project Overview

India Air Quality Analytics 2026 is an interactive Power BI dashboard project developed to analyze air pollution levels across various cities and states in India. The dashboard helps monitor pollution trends, identify highly polluted regions, and understand pollutant distribution through visual analytics.

---

##  Objectives

- Analyze air quality trends across India.
- Identify highly polluted cities and states.
- Compare pollution levels by pollutant type.
- Monitor AQI categories and pollution severity.
- Create an interactive dashboard using Power BI.

---

##  Data Cleaning & Processing

- Removed null values
- Filled missing values using the AVERAGEIFS method
- Removed duplicate records
- Standardized column names
- Corrected inconsistent data entries
- Applied filtering and formatting
- Cleaned and transformed data using Power Query
- Created DAX measures for KPI analysis
- Used SWITCH function to create calculated columns

---

## Tools & Technologies

- Power BI
- Microsoft Excel / CSV Dataset
- DAX Measures
- Power Query
- Data Visualization

##  Data Modeling

- The dataset used for this dashboard contains a denormalized table structure.
- All related data attributes are stored within a single consolidated table.
- Complex data modeling and schema creation were not required.
- Table relationships were not necessary for this analysis.

##  Key Insights

### 🔹 Descriptive Analysis

- The dashboard contains over 3.4K pollution records for analysis.
- The overall average pollution level recorded is 44.32.
- The maximum pollution value recorded in the dataset is 500.
- Analyzed AQI categories and pollutant distribution across India.

### 🔹 Diagnostic Analysis

- PM10 and PM2.5 are the major contributors to air pollution.
- Khora recorded the highest average pollution level among cities with an AQI value of 134.
- Himachal Pradesh showed the highest pollution level among states with an AQI value of 93.
- Pollution levels vary significantly across different regions.

### 🔹 Predictive Analysis

- Pollution levels may continue to increase in highly affected regions if current trends continue.
- Cities with consistently high AQI values may experience severe air quality conditions in the future.
- PM10 and PM2.5 pollutants are likely to remain major pollution contributors.

### 🔹 Prescriptive Analysis

- Focus on reducing PM10 and PM2.5 emissions in highly polluted regions.
- Strengthen pollution monitoring systems and environmental awareness programs.
- Encourage green initiatives and pollution control measures to improve air quality.
- Implement stricter environmental policies in high AQI regions.
